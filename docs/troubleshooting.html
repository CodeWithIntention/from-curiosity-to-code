Troubleshooting

Common beginner issues when trying to run Python files locally.

"python" is not recognized

Try python3 instead. If neither works, Python may not be installed correctly or may not be available in your terminal path.

The program closes immediately

Run the script from a terminal or command prompt so you can see the output and any error messages.

I get a syntax error

Check punctuation, indentation, quotes, and parentheses carefully. A single missing character can stop the program.

My version behaves differently

Compare your file to the matching chapter source in the repo. Small changes in spacing, logic, or indentation can change the result.
