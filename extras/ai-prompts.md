# AI Prompt Ideas for Readers

Use these as starting points.
Always read the code carefully before using it.

## Input handling
- In Python, how do I ask the user to input "y" or "n" to a yes or no question?
- How can I validate that a user entered a whole number before converting it to int?

## Gameplay improvements
- My guessing game asks the player to input guesses for a number from 1 to 100. How do I store guesses so I can prevent duplicates?
- How do I keep track of the best score in a Python guessing game?
- How do I save the best score to a text file and load it the next time the program runs?
- How do I let the user choose a custom minimum and maximum range before the game starts?

## Good follow-up questions
- Can you explain this code line by line?
- Can you rewrite this using only beginner-friendly Python features?
- Where should this code be inserted into my program?
- What could go wrong with this code?
