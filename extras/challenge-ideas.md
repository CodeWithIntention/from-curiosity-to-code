# Challenge Ideas

Here are some follow-on ideas for readers who want to keep going.

1. Prevent duplicate guesses from counting twice.
2. Track the best score during a session.
3. Save the best score between runs.
4. Allow the player to choose a custom minimum and maximum range.
5. Add a reusable yes/no helper function for replay.
6. Count invalid inputs separately.
7. Add difficulty levels.
8. Let the player choose how many rounds to play.
9. Show previous valid guesses after each turn.
10. Add a debug mode that can be turned on and off.
