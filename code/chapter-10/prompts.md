# Chapter 10 Prompt Examples

These prompt examples come from the spirit of Chapter 10.

The goal is not to blindly paste AI-generated code into your program.
The goal is to understand what the code does, decide whether it belongs, and integrate it properly.

## Prompt 1

Python Edition: In Python, how do I ask the user to input "y" or "n" to a yes or no question?
JavaScript Edition: In JavaScript, how do I ask the user to input "y" or "n" to a yes or no question?

## Prompt 2

My game asks the player to input guesses for a number from 1 to 100. How do I store the player's guesses so I can check if a guess has already been made and prevent duplicates?

## Reminder

AI can generate code quickly, but it cannot tell you whether that code belongs in your program.
That decision is yours.
